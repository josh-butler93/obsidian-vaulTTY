	* sudo chmod -R testdir --the -R applies the change recursively to all files and subdirectories
---
  - '-S': Sort by file size
  - '-X': Sort alphabetically by file extension
  - '-v': Sort by version (useful for numbered files)
  - '4': Read permissions
  - '2': Write permissions
  - '1': Execrute permissions
  - '0': No permission

#Sudo misc. Commands

	* sudo tee --this command combo is used write or append data to files owned by the root user simultaneously displaying the output on the screen
		--standard shell redirection operators like > or >> do not inherit sudo privileges
--ex:
  -sudo echo "127.0.0.1 mysite.local" >> /etc/hosts
  -echo "secret_key" | sudo tee /etc/secrete.txt > /dev/null

	#############################Quick Reference####################################
	#Overwrite a root file + see output-- echo "text" | sudo tee /path/to/file     #
	#Append to a root file + see output-- echo "test" | sudo tee -a /path/to/file  #
	#Write to a root file silently-- echo "test" | sudo tee /path/to/file > dev/nll#
