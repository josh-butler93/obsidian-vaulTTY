---Grep
	
	* -i: Perform case-insensitive searching
	* -c: Count the number of matching lines
	* -n: Display line numbers alon with matching lines
	* -v: Invert the match, showing lines that do not match the pattern
	* -r or -R: Recursively search through directories

---
	* cd /usr/share/doc
	* grep -r copyright --adding the '-r' flag to the grep command will search recursivley for all the files in the current directory tree that contains the text copyright
	* grep -rl copyright --adding the '-l' flag prints nothing more that the directory and file names 
	* grep -r copyright | wc --this will print just the numnber of lines,words, and characters in the output 
	* grep -R copyright | wc --the '-R' flag will recursively return even objects that are symbolic links 
	* ls -l /usr/share/doc/ | grep debconf 
	* cat git/README.source | grep extracted 
	* cat git/README.source | grep -A 2 extracted --this command will print out the two lines that follow the value you were looking for 
	* cat git/README.source | grep -B 5 extracted --this command will show the lines that follow the value you were looking for 
	* cat git/README.source | grep -C 4 extracted --this commannd will show the lines that come both before and after the value you are looking for
