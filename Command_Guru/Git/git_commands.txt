#Merging Branches --Reality Conjunction
	* git checkout master || git switch master
		--on the master branch the files created above are not there and wont exist until the branches are merged
	* git merge feature-dimension
	* git branch --merged --to see which branches were merged

#Closing the Branch ---Closing Dimensional Portal
	* git branch -d feature-dimension --the '-d' tells git to delete the branch
	* git branch -D feature-dimension ---the '-D' will delete the branch if git complains about anything 
	* git branch
	* git branch -a ---This command allows you to see all branches, including remote branches

#Git log commands
	* git log --name-only >> this command will list out the file name instead of the commit message
	* git log --oneline
	* git log --oneline --name-only
	* git log -n 3 >> to see the last 3 commits
	* git log --max-count=<number>
	* git log --graph --decorate
